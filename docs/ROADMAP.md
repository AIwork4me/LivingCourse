# Roadmap

LivingCourse remains deliberately small. The next work is prioritized only when it measurably raises non-technical manufacturing HR one-pass success.

## v0.2 follow-up

- Package or guide clean-machine FFmpeg/FFprobe discovery so `doctor` passes without shell expertise.
- Add deterministic ingestion adapters for the named source formats into candidate CourseSpec, with visible grounding links.
- Add a guided replacement flow for site PPE rules, real equipment photos, approved SOP/WI and verified device anchors.
- Validate more manufacturing courses without adding slide types or provider count prematurely.
- Measure first-pass build, review correction count, grounding completion and release-gate success.

## Explicitly out of scope

No Studio UI, LMS, quiz, PBL, interactive HTML, database, S3, accounts, collaboration system, WYSIWYG editor, background-agent platform, distributed job system or redundant provider matrix is planned for this milestone.

See [ONE-PASS-READINESS.md](ONE-PASS-READINESS.md) for the exit criteria that matter more than feature volume.
