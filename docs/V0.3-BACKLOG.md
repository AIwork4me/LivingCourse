# v0.3 Backlog

Items here were intentionally kept outside Core v0.2.1. They do not relax existing production release policy.

- Universal Material Intake for PDF, DOCX, PPTX and other raw source formats, including authority mapping and provenance.
- Workflow adapters that can supply provider-neutral aligned narration timing when an approved provider exposes it. Core v0.2.1 already defines and tests the seam; the Golden approved-reference workflow currently exercises the explicit estimated fallback.
- Guided collection and approval of site-specific device imagery, PPE requirements, grounding anchors and production review evidence.
- Clean-machine discovery and guided remediation for FFmpeg, FFprobe, CJK fonts and media dependencies.
- Additional slide types and their layout profiles, introduced only with independent contracts and repeated-type behavioral regressions.
- Studio, dashboard, LMS and remote persistence work after intake and grounding exit criteria are met.
